# SEAM 패턴 카탈로그

표시 이름은 한글, 내부 키는 영문입니다 (스펙 4절). 수치는 `seam/pine/presets.json.md` 참고.
v1 에서 뺀 것: 헤드앤숄더, 하모닉 (피벗 정의가 달라 오탐이 많음, v2).

## 2. 후보를 만드는 방법

새 피벗이 확정된 봉(오른쪽 `L` 봉이 닫힌 봉)에서만 후보를 계산합니다.

- **선 두 개 (삼각 · 쐐기 · 채널 · 박스)**: 주 피벗(`pivLen`)의 고점 쌍 × 저점 쌍. 각 쪽 최근 피벗 1~2개를 끝점으로, 그 앞 1~3개를 시작점으로 해서 쪽당 5쌍, 모두 25조합.
- **플래그 · 페넌트**: 보조 피벗(`minorLen`)으로 같은 방식 (쪽당 3쌍, 9조합). 구조 시작 직전에 깃대가 있어야 합니다.
- **W / M**: 새 주 저점(고점)과 그 앞 같은 쪽 피벗 1~2개.
- **컵**: 새 주 저점 = 핸들 저점. 그 직전 주 고점 = 오른쪽 립. 더 앞의 고점 최대 5개 = 왼쪽 립 후보.

한 봉에서 가족마다 가장 좋은 후보 하나만 잠급니다 (formal 우선, 그다음 점수).

## 3. 기하 분류 (선 두 개)

`rU`, `rL` = 구조 폭 전체에서 각 선이 움직인 양 (ATR 단위). `hL` = 왼쪽 끝 폭, `hN` = 인식 봉 폭.

1. 박스: 두 선 모두 앵커 쌍 가격차 `≤ boxFlatR` ATR → `BOX`. 두 앵커 평균에서 수평으로 잠급니다 (기울기 외삽은 피벗 잡음을 키우므로 박스 판정에 쓰지 않음).
2. 수렴 (`hN ≤ hL × convRatio`):
   - 상단 수평 · 하단 상승 → `TRI_ASC`
   - 하단 수평 · 상단 하락 → `TRI_DESC`
   - 상단 하락 · 하단 상승 → `TRI_SYM`
   - 둘 다 (수평이 아닌) 상승 → `WEDGE_RISING`, 둘 다 하락 → `WEDGE_FALLING`
3. 평행 (`|hN − hL| ≤ parTol × max`): 평균 기울기가 수평이면 `CHANNEL_FLAT`, 아니면 `CHANNEL_UP` / `CHANNEL_DN`.
4. 벌어지는 구조(확산형)는 v1 에서 버립니다.

플래그 모드에서는 같은 분류 뒤 깃대 방향으로 바꿉니다: 상승 깃대 + (하락채널 · 횡보채널 · 박스) → `FLAG_BULL`, 상승 깃대 + 삼각 → `PENNANT_BULL`. 하락 깃대는 대칭.

**깃대**: 구조 시작 봉과 그 앞 `2 × minorLen` 봉 안의 극값이 깃대 끝, 그 앞 `poleMaxB` 봉 안에서 `poleMin` ATR 이상 급하게 온 이동.

## 4. 품질 — 접점 · 관통 · 밀착 (PRINCIPLE 3)

- **접점**: 고가(저항선) 또는 저가(지지선)가 선에서 `maxGap × ATR` 이내인 봉. `minorLen` 봉 이내로 이어진 접촉은 1회.
- **관통**: 형성 구간에서 종가가 선 밖으로 `maxGap × ATR` 넘게 나간 봉 수.
- **밀착 (adhesion)**: 해당 쪽 보조 스윙 가운데 구조 중앙선 너머(선 쪽)에 있는 것, 즉 그 선을 시험한 스윙만 모읍니다.
  `gap = median(|스윙 − 선| / ATR)`, `adhesion = clamp(1 − gap / maxGap, 0, 1)`. 구조 밀착 = 두 선 평균.
  W / M 도 같은 방식(수평 극값선 · 넥라인)으로 계산해 다른 가족과 비교할 수 있게 했습니다. 컵은 두 립의 일치도를 씁니다.
- **점수** = 밀착 + 0.03 × (필요 접점을 넘는 접점 수, 최대 5).

## 5. 등급

아래 순서로 처음 걸리는 이유가 `reason` 이 되고 등급은 `reference` 입니다. 모두 통과하면 `formal`.

| 코드 | 패널 표시 | 조건 |
|---|---|---|
| `too_few_touches` | 접점 부족 | 선당 접점 < `minTouch` (플래그 · 페넌트는 `max(2, minTouch-1)`) |
| `line_float` | 선이 뜸 | 밀착 < `minAdh` |
| `line_cut` | 선 관통 | 형성 구간 종가 관통 > `maxViol` |
| `width_short` | 폭 부족 | 폭 < `minWidth` (60% 미만은 아예 버림) |
| `height_small` | 높이 부족 | 넓은 쪽 높이 < `minHeight` ATR (플래그 · 페넌트는 절반), W/M 깊이 < `wmDepth`, 컵 깊이 < `cupDepth` |
| `origin_mismatch` | 시작점 어긋남 | 두 선의 첫 앵커가 폭의 절반 넘게 떨어짐. W/M 은 첫 피벗 앞 추세가 넥라인 너머 깊이의 절반까지 오지 않음 |
| `pole_weak` | 깃대 약함 | 깃대 높이 < 깃 높이 × 1.5 |
| `flag_deep` | 깃 되돌림 과다 | 깃이 깃대를 `flagRetr` 넘게 되돌림 |
| `peaks_unequal` | 두 피벗 불일치 | W/M 두 피벗 차 > min(`peakTol` ATR, `peakPct` × 가격). 컵은 립 차이 > `lipTol` × 깊이 |
| `handle_deep` | 핸들 과다 | 핸들 깊이 > 컵 깊이 × `handleMax` |
| `cup_shape` | 컵 비대칭 | 컵 바닥이 폭의 20~80% 밖 |
| `base_too_deep` | 베이스 과다 | 컵 깊이 / 립 가격 > `cupMaxPct` |
| `rr_lt_1` | 거리비 1 미만 | 고전 방향이 있는 구조에서 (측정 목표까지 거리) / (반대 경계까지 거리) < 1 |

아예 버리는 경우 (그리지 않음): 폭 과소/과대, 인식 봉 종가가 이미 선 밖, 관통이 `maxViol + 2` 초과, 밀착 0.15 미만, 수렴 구조가 꼭짓점에 너무 가까움, W/M 두 피벗 사이에 같은 쪽 피벗이 또 있음(삼중), 이미 넥라인을 넘은 W/M, 이미 립을 넘은 컵.

## 6. 잠금 뒤 (스펙 6.5)

잠긴 선을 시간으로 연장한 값(`liveUpper`, `liveLower`)과 **확정 종가**만 비교합니다. 버퍼 = `brkBuf × ATR`.

| 지금 | 조건 | 다음 | 이벤트 |
|---|---|---|---|
| locked | 종가 > liveUpper + 버퍼 | break_up | `break_up` |
| locked | 종가 < liveLower − 버퍼 | break_down | `break_down` |
| locked | lock 뒤 유지 봉 초과, 또는 수렴 구조 남은 폭 ≤ `apexAtr` | expired (끝) | `expire` |
| break_* | 반대 경계를 종가로 이탈 | failed (끝) | `fail` |
| break_* | `retestMax` 봉 안에 잠긴 선으로 돌아와 버팀 | hold_retest | `retest` (1회) |
| break_* / hold_retest | 돌파 뒤 `postKeep` 봉 경과 | 조용히 추적 종료 | — |

고전 방향과 반대로 먼저 깬 것도 `break_*` 입니다 (failed 아님). 라벨만 다릅니다.

## 7. 겹침과 표시 (스펙 6.4)

- 같은 가족의 잠긴(미돌파) 구조와 형성 구간이 50% 이상 겹치거나, 가족이 달라도 지금 경계가 사실상 같은 선이면 경쟁합니다.
  새 후보가 formal 이고 기존이 reference 이거나, 점수가 `supMargin` 이상 높을 때만 교체합니다. 교체는 기존 구조의 값을 고치지 않고 추적만 끝냅니다.
- 표시 슬롯 (formal): 1 점수 최고 · 2 폭 최대 · 3 높이 최소. 슬롯에 있는 formal 만 lock 알림을 보냅니다. 한 번 알린 구조의 이후 이벤트는 슬롯에서 밀려도 보냅니다.
- reference 는 표시 개수만큼 흐리게 그리고, 추적이 끝나면 지웁니다. formal 은 끝난 뒤에도 역사로 남습니다.
